# 隐私实践与权限字段

## 单一用途

在用户主动操作时，把当前公众号文章保存为含图片的本地 Markdown，再把用户选定的 Markdown 导入到其 X Articles 草稿。

## `downloads` 权限

用户在公众号文章页点击“下载 Markdown”后，扩展需要使用下载 API 将 `.md` 和原文图片写入浏览器下载目录下同一个文章文件夹，并可显示已下载文件。此操作只在用户触发后发生。

## 主机与页面访问

- `https://mp.weixin.qq.com/*`：内容脚本只在公众号文章页读取当前文章的标题、正文、图片及出处，为用户生成本地 Markdown。
- `https://mmbiz.qpic.cn/*`：当文章页无法直接取得原图时，后台脚本从微信图片服务抓取文章内图片。
- `https://mmbiz.qlogo.cn/*`：同上，用于可能位于该域名的文章封面或图片。
- `https://x.com/*`、`https://twitter.com/*`：内容脚本在 X 页面显示导入入口；只有用户选择 Markdown 并点击导入后，才在 X Articles 编辑器中写入草稿。支持这两个域名是为了兼容现有文章编辑器入口与跳转。

## 远程代码

选择“否”。`wechat.js`、`x.js`、`x-main.js`、`ui.js`、`sanitize.js`、`background.js` 和 `lib/marked.min.js` 都随 ZIP 提供。扩展从网页和用户文件读取的是文章、Markdown 和图片数据，不下载并执行远程脚本。

## 数据使用声明

- 网站内容：是。扩展读取用户当前公众号文章，并在 X 编辑器写入用户指定的内容。
- 用户提供的本地文件：是。仅在用户选择或拖入文件后读取 Markdown 和配图。
- 个人身份信息：不专门收集；文章或 Markdown 自身可能包含作者名等个人信息，扩展只按用户要求转换。按开发者后台当前字段说明核对。
- 身份验证信息、支付信息、健康信息、精确位置、浏览记录、私人通信：扩展不主动读取这些类别。若用户自己将此类内容写入选定文章，仍只为导入流程处理。
- 处理位置：用户浏览器与下载目录；导入草稿时内容由 X 接收。
- 开发者服务器、广告、分析、出售数据：均无。
- Limited Use：确认 Chrome API 获取的数据仅用于用户可见的导出、下载和导入功能。

后台复选框应与实际提交 ZIP、公开隐私政策及当时的字段定义一致。
